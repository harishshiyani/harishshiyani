Harish Shiyani - Portfolio Website

Kaise kholein:
1. Zip ko Extract karein.
2. index.html par double-click karein (Chrome / Edge / Firefox mein khulega).

Edit karne ke liye:
- VS Code mein folder kholein (File > Open Folder).
- Text badalne ke liye index.html edit karein.
- Photo badalne ke liye images/profile.jpg replace karein (same naam rakhein).

Note: Fonts ke liye internet chahiye. Bina internet ke bhi site chalegi, bas font alag dikhega.
